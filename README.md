# personal-calendar

The homepage and privacy policy for **Karan Personal Calendar**, a private, single-user tool that manages its owner's own Google Calendar from his computer.

Google requires a published OAuth app to link a public homepage and privacy policy on an authorized domain. These two pages are served with GitHub Pages:

- Homepage: https://war-owl.github.io/personal-calendar/
- Privacy policy: https://war-owl.github.io/personal-calendar/privacy.html

**Don't delete or rename this repo, or turn off Pages.** The Google app's consent screen points at these URLs, and the app can be pulled back from production if they stop resolving.

This repo contains only these pages. No code, credentials or calendar data live here.
