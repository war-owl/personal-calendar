Privacy Policy

Karan Personal Calendar · Last updated 22 October 2026

Karan Personal Calendar is a private tool used only by its owner, Karan Bhardwj, with his own Google account. It is not offered to anyone else.

What it accesses

With the owner's permission, it uses two Google Calendar scopes:

  • calendar.readonly: to see his list of calendars and their events.
  • calendar.events: to create, edit and delete events when he asks.

It does not change calendar settings or sharing, and it does not access Gmail, Drive, contacts or any other Google data.

Where data goes

  • The tool runs on the owner's own computer. Its Google sign-in tokens are stored only there, in a file readable only by his user account.
  • Calendar details are fetched from Google only when the owner asks for them. When he uses the tool through an AI assistant (Claude, by Anthropic), the details returned are sent to that assistant to answer his request.
  • There is no separate server or database. Data is not sold, shared with anyone else, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time from myaccount.google.com/permissions, which stops the tool from reading or changing the calendar.
